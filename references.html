Annotated bibliography

Six primary research sources

References are numbered in order of first appearance in the overview diagram. Reliability assessments are our judgments of what each source supports, rather than a claim that publication status alone establishes validity. Paper locations accompany key claims throughout the tutorial.

[01]

FormCoach: Lift Smarter, Not Harder

Xiaoye Zuo, Nikos Athanasiou, Ginger Delmas, Yiming Huang, Xingyu Fu, and Lingjie Liu

2025 · arXiv:2508.07501v3 · preprint

Read the primary source ↗

Synopsis
Pairs user/reference exercise clips and evaluates VLM corrective feedback on 1,700 annotated pairs over 22 exercises. Separates accuracy, actionability, and hallucination.
Reliability assessment
Medium: highly relevant primary benchmark; preprint and automated LLM judging limit the evidence. No demonstrated user-improvement outcome.
Key locations
§2–4; Tables 1–2

[02]

Real-Time Feedback and Benchmark Dataset for Isometric Pose Evaluation

Abhishek Jaiswal, Armeet Singh Luthra, Purav Jangir, Bhavya Garg, and Nisheeth Srivastava

2025 · arXiv:2506.11774 · preprint

Read the primary source ↗

Synopsis
Introduces six-pose isometric data and compares angle features, motion prediction, and graph models. Explains peak-based segmentation, angle histograms, and a three-part correctness/error/confidence metric.
Reliability assessment
Medium: primary methods and comparison tables, but small male-only population, restricted frontal/no-occlusion capture, and no measured full-loop latency.
Key locations
§3–7; Tables 2–4; Algorithm 1

[03]

Pose Trainer: Correcting Exercise Posture Using Pose Estimation

Steven Chen and Richard R. Yang

2020 · arXiv:2006.11718 · research report

Read the primary source ↗

Synopsis
OpenPose prototype for four dumbbell exercises, using torso normalization, geometric thresholds, and DTW nearest-neighbor classification. Gives explicit rules and small-test-set F1 values.
Reliability assessment
Medium for implementation, low for generalization: inspectable algorithms and code, but tiny tests and no demonstrated mobile live loop.
Key locations
§4.3–4.7; Table 1

[04]

AIFit: Automatic 3D Human-Interpretable Feedback Models for Fitness Training

Mihai Fieraru, Mihai Zanfir, Silviu-Cristian Pirlea, Vlad Olaru, and Cristian Sminchisescu

2021 · CVPR · pp. 9919–9928 · peer reviewed

Read the primary source ↗

Synopsis
Reconstructs 3D pose, segments repetitions, builds active/passive exercise signatures, and produces statistical reference-grounded feedback. Fit3D uses subject-separated evaluation.
Reliability assessment
High for reported method evaluation: explicit algorithms, lab ground truth, and held-out subjects. Feedback agreement is with the system’s ground-truth-3D coach, not independent proof of user improvement.
Key locations
§3–5; Tables 1–3; Figs. 6–7; Listing 1

[05]

SiTrEx: Siamese transformer for feedback and posture correction on workout exercises

Abdellah Sellam, Dounya Kassimi, Abdelhadi Djebana, and Sara Mokhtari

2025 · Neurocomputing 658, 131703 · peer reviewed

Read the primary source ↗

Synopsis
Angle Usefulness and Angle Similarity Transformers select important angles and compare coach/athlete temporal sequences. Evaluates 727 videos, exercise-held-out transfer, and smartphone processing time.
Reliability assessment
High for explicit algorithms and measured mobile component runtime; generalization is qualified by small, imbalanced source data and random-sample rather than participant-separated folds.
Key locations
§3–5; Algorithms 1–2; Tables 6, 9; Fig. 9

[06]

Real-Time Posture Correction of Squat Exercise: A Deep Learning Approach for Performance Analysis and Error Correction

Prashant Rao, C. S. Asha, and P. Raghavendra Rao

2025 · IEEE Access 13, pp. 39557–39571 · peer reviewed

Read the primary source ↗

Synopsis
Uses stereo video, MediaPipe, temporal Bi-CGRU plus attention, and regression to corrected poses. Reports a 1,332-video squat dataset and 96.10% classification accuracy.
Reliability assessment
Medium-high for the within-dataset architecture comparison; monocular mobile transfer remains untested here, participant separation is not established, and the reported regression accuracy terminology is ambiguous.
Key locations
Abstract; methods; Table 2
